# Tapstate Web UI

`@tapstate-web/ui` contains the shared source components and styles used by Web and Cloud. The `src/` directory keeps the component source layout directly; public subpaths map to those source files in `package.json`.

Import components through their public subpaths, for example `@tapstate-web/ui/button`, `@tapstate-web/ui/dialog`, and `@tapstate-web/ui/search-input`. Import `@tapstate-web/ui/styles.css` once after Tailwind in each app's stylesheet, scan the package source and register its icon plugin as shown in [Styling](docs/styling.md).

There is no package root barrel. App-specific behavior such as Formily bindings, localized providers, and route navigation belongs in the applications and should compose these source components.

The imported `src/` snapshot retains its source formatting and is excluded from the app formatter, using the direct source path after migration. Root code lint and package typecheck still cover it. Generated source-study JSON is likewise regenerated by its analyzer rather than reformatted by the app formatter.
