# System interaction audit

This is the inventory and acceptance ledger for interaction primitives inside the Tapstate Web and Cloud shells. It supplements [DESIGN.md](DESIGN.md) and the per-page ledger in [ui-page-audit.md](ui-page-audit.md). A package import proves provenance, not correct use on a business screen. Each family remains open until the relevant screens have been inspected in their real states.

Source baseline: upstream revision in `packages/dify-ui/UPSTREAM.md`. Upstream contracts: `packages/dify-ui/docs/overlays.md`, `forms.md`, `selection.md`, `accessible-names-and-descriptions.md`; source files named below. Tapstate keeps its brand, navigation and outer shells.

## Screen review protocol

For each new or changed screen, record the actual interaction path: trigger → open → keyboard navigation → confirm/cancel or Escape/outside click → resulting data state → focus return. Inspect nested overlays, disabled/pending states, long text, mobile viewport, light/dark where supported, and en/zh-CN/zh-TW labels. Capture screenshots at 1280×800 and 375×812 and link the evidence from the page audit. Mark a family/screen complete only after its rendered behavior and source import are both verified; typecheck and UI Kit alone do not close a business-page row.
